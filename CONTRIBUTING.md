# Contributing

This is a planning repository. Discuss the problem, evidence and proposed acceptance criteria before adding implementation. Do not upload customer telemetry, credentials or proprietary runbooks. Use clearly labeled synthetic examples.

For documentation changes: check relative links, update assumptions and research dates, distinguish targets from results, and run the financial calculator if changing costs. Include primary sources for competitive claims. Never claim an implementation, benchmark or control exists without evidence.

Before accepting external code, establish a license, verified rights holder and contribution policy. Once implementation begins, changes need focused tests, dependency review and the security gates in the roadmap. Vulnerability reports follow [SECURITY.md](SECURITY.md), not public issue templates.
